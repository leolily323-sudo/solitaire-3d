# 🎴 Solitaire 3D

A mobile-friendly 3D Solitaire experience built as a lightweight web game, with customizable tables, card backs, themes, and classic Klondike gameplay.

## 🎮 Play Now

Live Demo:  
[Solitaire 3D](https://solitaire-3d-sepia.vercel.app/)

## ✨ Features

- 🃏 Classic Solitaire / Klondike gameplay
- 🌌 Full-screen 3D card table
- 🎨 Multiple table themes
- 🂠 Customizable card backs
- 🔄 Draw-1 and Draw-3 gameplay
- ↩️ Undo support
- 🤖 Auto-play assistance
- 🏆 Score and move tracking
- ⏱️ Game timer
- 💾 High-score tracking
- 🔊 Sound controls
- 📱 Designed for mobile and touch controls
- ✨ AI-inspired theme generation concept

## 📱 Built For Mobile

Solitaire 3D is designed to work comfortably on mobile devices while remaining playable on desktop browsers.

The game uses a responsive full-screen interface and touch-friendly controls.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Three.js

The project currently uses a lightweight browser-based architecture so the game can run without a backend.

## 🚧 Project Status

**Current status:** Playable prototype / active development

The core game is playable and deployed publicly. Development is focused on polishing the experience, improving mobile usability, testing gameplay, and preparing the project for a future production release.

## 🧪 Testing

The game is currently being tested on real mobile devices and with real players.

Feedback and gameplay testing are being used to identify bugs, usability issues, and areas for improvement.

## 📂 Project Structure

The current version is intentionally lightweight and primarily browser-based.

The main game is served through the project's web entry point and can be deployed directly through services such as Vercel.
